# Greedy Algorithms

## 📖 What is a Greedy Algorithm?

A Greedy Algorithm makes the best possible choice at the current step, hoping it leads to the optimal solution.

---

## 🧠 My Problem Solving Framework

1. Identify the Pattern
2. Initialize Variables
3. Write the Loop
4. Find the Condition
5. Update Variables
6. Store Result (if needed)
7. Return Answer
