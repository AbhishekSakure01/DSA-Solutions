# BST (Binary Search Tree)

This folder contains my practice problems on Binary Search Tree.

I’m using this to improve my understanding of tree concepts and get better at DSA for exams and interviews.

---

## Notes

* In BST, left node is smaller and right node is greater than root
* Inorder traversal gives sorted output
* Time complexity is usually O(log n), but can go O(n) in worst case
